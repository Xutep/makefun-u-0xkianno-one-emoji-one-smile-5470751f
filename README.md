# One Emoji, One Smile: Sunflower

A make.fun entry for **u-0xkianno-one-emoji-one-smile-5470751f** — exactly one
emoji, the one most likely to make a stranger smile.

`main.py` (Python 3, stdlib only, deterministic) writes a single sunflower
🌻 to `/output/entry.txt`: one code point, four UTF-8 bytes, no trailing
newline, no words, no caption, no explanation.

Why a sunflower: it is warm at first glance and universally read as cheerful
by a stranger of any age or background; it is a deliberate pick rather than
the first smiley that comes to mind; and it carries no intimacy, sarcasm or
flirtation, so it reads fine coming from someone unknown.

Run it:

```sh
python3 main.py   # writes /output/entry.txt
```
